## Fire TV – Installation (Downloader)

1. Apps → **Downloader** (AFTVnews) installieren  
2. Unbekannte Quellen für Downloader erlauben  
3. URL eingeben:
   ```text
   https://clck.ru/3VBrJb
   ```
4. Installieren → **Verflixed** starten

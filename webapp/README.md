# Verflixed Desktop Webapp

Lokale Desktop-App (Electron) für **macOS**, **Windows** und **Linux** – Stand **1.13.0** (1:1 mit Fire-TV 1.12.0).

## Features (1.13.0)

- 3D-Intro + Brand-Sting wie die APK (Splash und Player-Pre-Roll)
- Home-Hero, Portrait-Poster, Glass-Flächen, tvOS-Motion
- Sidebar ohne Desktop-Chrome (Quellen-URL in den Einstellungen)
- Zoom, Kategorie-Filter (Horror/Anime standardmäßig aus), „Weil du X geschaut hast“
- Smarter Weiterschauen, echte „Neu erschienen“-Filme, Progressbars
- Favoriten: Streams bulk bis HLS/MP4 cachen + Status-Pille
- Detail ⋯ : Cache leeren, Zufallsfolge, aus Weiterschauen entfernen
- Player: Intro/Abspann-Buttons, nächste Folge, Captcha bleibt sichtbar
- Profile, DE/EN, Update-Check über GitHub Releases

```bash

npm install
npm start
```

Oder Zip entpacken und `Start-macOS.command` / `Start-Windows.bat` nutzen.
